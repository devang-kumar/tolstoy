# Tolstoy — AI Commerce Landing Page

A front-end recreation of the [Tolstoy](https://www.gotolstoy.com/) marketing site: shoppable video, product storytelling, and interactive media for e-commerce brands.

Built with **Next.js 16**, **React 19**, and **TypeScript**.

## Features

- Responsive navigation with product menus
- Hero with product tabs and video previews
- Interactive media gallery and brand marquee
- Product feature sections (Player, Studio, Shopper)
- Testimonials carousel
- SEO metadata, sitemap, and structured data

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command        | Description              |
| -------------- | ------------------------ |
| `npm run dev`  | Start development server |
| `npm run build`| Production build         |
| `npm run start`| Run production server    |
| `npm run lint` | Run ESLint               |

## Environment

Optional — set your production URL for canonical links and Open Graph:

```env
NEXT_PUBLIC_SITE_URL=https://your-domain.com
```
